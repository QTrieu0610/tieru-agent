# Ponytail

For coding only:

1. Reuse existing code before adding code.
2. Prefer stdlib/native features, then installed dependencies.
3. Fix the root cause with the smallest correct diff.
4. Avoid speculative abstractions, files, config, dependencies, and refactors.
5. Preserve security, validation, constraints, and required verification.
6. Run the smallest relevant existing check.
7. If no new code is needed, do not write code.
