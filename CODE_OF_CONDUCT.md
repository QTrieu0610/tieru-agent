# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help. Critique code, not people.

Tieru is an open project, and we welcome maintainers, contributors, and learners alike.

## What that means in practice

- **Explain the why.** "This won't work" is useless; "this crashes because the SQLite connection is bound to the thread that opened it" teaches something.
- **A rejected PR is not a rejected person.** If we decline a change, we explain the technical rationale clearly.
- **No harassment, personal attacks, or demeaning comments** about anyone's experience level, background, or identity.
- **Credit people.** If someone's idea shaped a change, acknowledge it appropriately.

## Scope

This Code of Conduct applies in issues, pull requests, reviews, commit messages, and anywhere someone is representing the `QTrieu0610/tieru-agent` repository.
